# Spam Detection ML Project

This project detects spam messages using Machine Learning and NLP.

## Features

- Naive Bayes Model
- TF-IDF Vectorization
- 97% Accuracy
- Streamlit Web App

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- NLP

## How to Run

Install libraries:

pip install -r requirements.txt

Run web app:

python -m streamlit run app.py
